# Tesserix Crew v0.4.4

`/workflow` now starts with an overview: current step, completed and pending work, role/provider/model assignments, approval gates, latest result, recorded-check counts, and the next action.

Press `d` to jump to the full review, `o` to return to the overview, or `f` to refresh. Approval still requires confirmation and rejects an outdated reviewed revision. Recorded checks remain labelled historical and are revalidated before closure.

macOS builds are Developer ID signed and Apple notarized. Upgrade with `brew upgrade --cask tesserix/tap/crew`.
